被赋予的人格 / Endowed Personhood

三一棱镜新词定义 · 首发于 Faith-Reality Gap Audit 第三篇《Endowed Personhood｜被赋予的人格》 · Markdown 纯文本版

🪞 导读

作者给“人身上被赋予的、不可随意取消的价值”起的名字——当公司用 AI 给员工生成“人才画像”，当“有用”不再是人的专利，这个词回答：人的尊严从何而来？

定义权声明：“被赋予的人格”为作者三一棱镜原创词汇，定义权归作者。本条目的一句话定义与关键区分逐字取自作者第三篇原文，不做改写。

一、问题背景

旧词“价值”“尊严”今天大多被当作产出和评分的同义词在使用；“人才画像”则直接把一个人翻译成一份数据档案。它们能描述“你能生产多少”“你得了几分”，但描述不了一种更根本的东西：有些东西不是你赚来的，不是因为你的表现、效率或别人给你打了多少分，而是你在成为一个人的时候，就已经被赋予了某种不可随意取消的价值。

当机器开始拥有越来越强的生产能力，我们必须重新回答：如果“有用”不再是人的专利，那么“人”本身还有什么意义？旧词不够用，就需要起一个新名字。这就是“被赋予的人格”被提出的原因。

二、一句话定义

Endowed Personhood｜被赋予的人格：Your value is not a function of your output. 人的价值，不是生产力的函数。

（作者定稿版，逐字取自 Faith-Reality Gap Audit 第三篇文末，不做改写）

三、关键区分

“于是，一个非常危险的转换正在发生：Person→Profile（人→人才画像），Value→Metrics（价值→指标），Dignity→Performance（尊严→表现）。我把这种趋势叫作：Reductionism of Personhood｜人格还原论。”

（逐字取自作者原文）

“不是说数据没有价值，恰恰相反，数据非常有用，问题是：当我们用数据描述一个人时，我们会不会慢慢开始把这个人本身等同于数据？这是两个完全不同的事情：你的工作表现可以被量化，但你不是你的工作表现；你的能力可以被评估，但你不是你的能力评分；你的行为可以被预测，但你不是一个预测模型。”

（逐字取自作者原文）

核心方向：You are not valuable because you produce. You produce because you are already valuable. 你不是因为能够生产，所以才有价值，而是因为你本身有价值，你的生产才有意义。这两个方向完全不同。

四、使用场景

  • 职场评估语境：用“被赋予的人格”提醒——AI 可以分析员工生成“人才画像”，但人才画像不是人；工作表现可量化 ≠ 人是工作表现。
  • 呼应系列开放问题：第 0 篇的开放问题“人的尊严从何而来？”——“被赋予的人格”就是这个问题在词汇层面的答案。
  • 讨论“有用”与“人”：当“有用”不再是人的专利，不追问“人怎样变得比机器更有用”，而是重新承认：人的价值从来不应该建立在“有用”之上。
  • 守住一条线：AI 时代最需要守住的一条线——不要让“效率”偷偷成为“尊严”的新定义。

常见问题

“被赋予的人格”是什么意思？

这是三一棱镜为“人身上被赋予的、不可随意取消的价值”起的名字。“Endowed”意味着：有些东西不是你赚来的，不是因为你的表现、效率或别人给你打了多少分，而是你在成为一个人的时候，就已经被赋予了某种不可随意取消的价值。作者定稿版一句话定义：“Endowed Personhood｜被赋予的人格：Your value is not a function of your output. 人的价值，不是生产力的函数。”

“你不是你的工作表现”是什么意思？

这是“Reductionism of Personhood｜人格还原论”的三组区分句：你的工作表现可以被量化，但你不是你的工作表现；你的能力可以被评估，但你不是你的能力评分；你的行为可以被预测，但你不是一个预测模型。数据非常有用，但当用数据描述一个人时，不能把这个人本身等同于数据。
